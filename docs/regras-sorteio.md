# Regras de sorteio

## Regras básicas

1. Todos os jogadores confirmados participam.
2. Goleiros identificados devem ser distribuídos entre os times sempre que houver goleiros suficientes.
3. A quantidade de jogadores deve ser equilibrada.
4. O usuário pode corrigir qualquer classificação antes do sorteio.
5. O resultado do sorteio pode ser repetido caso o usuário queira refazer.

## Modos

### Sorteio automático

Distribui os jogadores entre os times.

### Draft

Um capitão escolhe jogadores alternadamente.

### Par ou ímpar

O sistema pode gerar um número aleatório para definir quem começa o draft.
