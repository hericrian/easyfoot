# EasyFoot — Frontend

PWA em React + TypeScript + Vite, publicado em https://easyfoot.pages.dev.

```bash
npm install
npm run dev        # desenvolvimento
npm test           # testes (Vitest)
npm run build      # typecheck + build em dist/
npm run pages:dev  # simula o Cloudflare Pages (aplica _headers)
npm run deploy     # publica no projeto Pages "easyfoot"
```
